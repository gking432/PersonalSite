# Homepage traffic miniature

This directory is the single-intersection website version: one light control, a working boat bridge, continuous traffic and immediate car/boat falls after crashes or queue overflow. No levels or rescue tools are included.

The full progression game is preserved in [`games/milwaukee-traffic`](../../../games/milwaukee-traffic/README.md). Its source is independent of this directory.

See [`docs/traffic-city.md`](../../../docs/traffic-city.md) for behavior, implementation and verification. The runtime and Three.js load only on desktop, after the 701px breakpoint; page physics load on activation. Keyboard controls and the site's normal cursor remain available.
